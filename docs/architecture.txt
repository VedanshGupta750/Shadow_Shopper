Storage:
  - Filesystem cache for ScraperAPI responses (SHA-1 keyed, 7-day TTL)
  - localStorage on client for analysis history (cap 20 entries)
  - No database — server is stateless

Streaming:
  - SSE from /api/stream-personas with heartbeats every 15s
  - Per-persona token streams + per-cell surfacing events + synthesis-token + done

Auth & rate limits:
  - No user auth (single-tenant demo)
  - express-rate-limit at 10 req/min per IP on POST endpoints
  - Optional /metrics endpoint gated by X-Admin-Secret header
